This part of the SDK supports development with [Capacitor](https://capacitorjs.com) and frameworks like [Ionic Framework](https://ionicframework.com)
that are based on Capacitor.

Multi-Plattform Capacitor Plugin that supports:
* iOS
* Android

The implementation is based on our [native libraries](/mobilesdk/native-libraries).

For more information please see:
[Github Repository](https://github.com/evva-sfw/abrevva-capacitor)

[NPM Package Repository Entry](https://www.npmjs.com/package/@evva/abrevva-capacitor)
