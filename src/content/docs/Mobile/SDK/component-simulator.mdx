To enable mobile app development without requiring an EVVA component (hardware), we are providing an Android mobile application
that allows to simulate an EVVA component.

In this application you can configure:
- parameters for the advertisement that may modify your app's UX/UI 
- the reaction to the disengage, to allow easy UX/UI implementation and testing of the possible disengage outcomes, including errors.

[EVVA Component Simulator](https://play.google.com/store/apps/details?id=com.evva.componentsimulator)
