Authentication is the process of verifying the identity of a [person (people)](/domain/concepts/people).

In access control systems, it mainly serves the purpose to verify that an [Identification Medium](/domain/concepts/identification-medium) used by somebody
at an [Access component](/domain/concepts/access-component) belongs the same installation, before it is used for [Authorization](/domain/concepts/authorization) 
purposes.

See also [Authentication@Wikipedia](https://en.wikipedia.org/wiki/Authentication)
