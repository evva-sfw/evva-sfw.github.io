Defines a logical set of [Authorizations](/domain/concepts/authorization) for [Installation points](/domain/concepts/installation-point) and 
[Zones](/domain/concepts/zone). It organizes authorizations to make them easier to assign to a [Person](/domain/concepts/person) as a standard default, 
respectively an [Identification Medium](/domain/concepts/identification-medium) for authorization.
