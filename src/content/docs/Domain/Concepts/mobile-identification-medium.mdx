Is a digital form of [identification medium](/domain/concepts/identification-medium) that can be stored and used on a mobile phone.

We offer a corresponding app for [Apple Devices](https://apps.apple.com/us/app/xesar/id6447353802) and [Android Devices](https://play.google.com/store/apps/details?id=com.evva.abrevva).
This documentation is supposed to help with adding this feature to your own mobile application. It's best if you start at the [Mobile SDK Overview](/mobilesdk/overview/).
