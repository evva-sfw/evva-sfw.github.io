A time series exception defines an alternative [Time window](/domain/concepts/time-window) for specific [Calendar Days](/domain/concepts/calendar-days).
The alternative time window will temporally restrict [Authorizations](/domain/concepts/authorization) different to the given weekday
of the [Time Series](/domain/concepts/time-series).

The system can provision 5 different special days and assign a number of [Calendar Days](/domain/concepts/calendar-days) to each of these.

### Example

Special day 1: 08:00-12:00
