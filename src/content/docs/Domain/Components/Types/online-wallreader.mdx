EVVA access control component that consists of a reader unit an an online control unit.

The online control unit is to be mounted in a secure area.
It connects:
- to a reader unit that is to be mounted in public accessible places like for example on a wall close to an entrance with an automatic door. 
- to a network adapter that connects it to a network and the Xesar Software
