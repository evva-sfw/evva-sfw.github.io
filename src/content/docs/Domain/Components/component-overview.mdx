EVVA mechatronical components can be installed at an [Installation Point](/domain/objects/installation-point/) to enable access control.
[People](/domain/objects/people) that require access are authenticated and authorized using an [Identification Medium](/domain/objects/identification-medium) or a [Mobile Identification Medium](/domain/objects/mobile-identification-medium).

The access control decision is taken offline in the component.
Components can be provisioned with configuration from an access control management backend, using a serial or wireless connection from a programming device.

### Interfaces

| Interface |  Description |
| ----------- | ----------- | 
| UART (Single Wire) | Serial interface for a connector that can be attached to the component. |
| RFID | Low range wireless interface (RFID) for interacting with an [Identification Medium](/domain/objects/identification-medium) |
| BLE | Bluetooth Low Energy interface for wireless interaction with the component. |
