EVVA mechatronical access components can be installed at an [Installation Point](/domain/concepts/installation-point/) to enable access control.
[People](/domain/concepts/person) that require access are authenticated and authorized using an [Identification Medium](/domain/concepts/identification-medium)
or a [Mobile Identification Medium](/domain/concepts/mobile-identification-medium).
Following privacy by design principles, the EVVA access control system is designed in a way that you are not required to administrate people and their
personal data - if you want to, you can work with identification media only.

The access control decision is always taken offline in the access component.
Access components can be provisioned with configuration data from an access control management backend, using a serial or wireless connection from a
 [Maintenance Component](/domain/concepts/maintenance-component).

### Interfaces

| Interface |  Description |
| ----------- | ----------- |
| UART (Single Wire) | Serial interface for a connector that can be attached to the component. |
| RFID | Low range wireless interface (RFID) for interacting with an [Identification Medium](/domain/concepts/identification-medium) |
| BLE | Bluetooth Low Energy interface for wireless interaction with the component. |
